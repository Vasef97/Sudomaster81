To all Sudoku lovers 🧠

Since I’m a big Sudoku enthusiast myself, I decided to build my own Sudoku game as a side project.

Introducing Sudomaster81, a full-stack, fully responsive web app powered by an intelligent board generator called Sudokugen. It creates unique, mathematically valid puzzles across four difficulty levels, calibrated based on the solving techniques typically required. From Naked Pair and Pointing Pair to advanced patterns like XY-Wing, Swordfish, Advanced Coloring and Nishio, every board is designed to challenge logical thinking.

The app also features a performance driven scoring engine that rewards speed and accuracy, optional mistake limits, candidate modes, leaderboards, customizable themes, and save & resume functionality.

Tech stack: Spring Boot, Spring Security, PostgreSQL, React 18, Docker

The application is deployed on a free tier service, so the first load may take approximately 1–2 minutes.

Try it here: https://sudomaster81.onrender.com/
